# Чатлинк — генератор ссылок в Telegram

Инструмент для владельца сайта: укажите свой Telegram-аккаунт и заранее составленное сообщение, затем скопируйте ссылку и вставьте её в кнопку на сайте. По этой кнопке посетитель откроет личный чат с вами; сообщение уже будет в поле ввода, останется нажать «Отправить». Вход в Telegram и Premium для работы генератора не нужны.

## Быстрый запуск на компьютере

Распакуйте ZIP в папку и откройте `index.html` в браузере. Сборка, Node.js и установка пакетов не нужны. Если браузер запрещает доступ к буферу обмена, приложение выделит ссылку для ручного копирования.

## Загрузка на обычный сервер

1. Распакуйте ZIP.
2. Загрузите **содержимое архива** в корень сайта (`public_html`, `www` или аналогичную папку хостинга) либо в отдельный подкаталог, например `telegram/`.
3. В этой папке должны лежать `index.html`, `styles.css`, `link-core.js`, `app.js` и `favicon.svg`. Также можно загрузить `.nojekyll` и `README.md`.
4. Откройте `https://ваш-домен/` или `https://ваш-домен/telegram/`.

Используйте HTTPS: доступ к буферу обмена в браузерах зависит от безопасного соединения и разрешений. Отдельная база данных, PHP, API-ключи или сервер приложения не нужны.

## GitHub Pages через браузер

1. Войдите в GitHub и откройте https://github.com/new.
2. Создайте публичный репозиторий, например `telegram-link-generator`.
3. На странице репозитория нажмите **Add file → Upload files**. В пустом репозитории можно нажать ссылку **uploading an existing file**.
4. Загрузите распакованные файлы из ZIP. `index.html` должен быть прямо в корне репозитория, а не внутри дополнительной папки. **Сам ZIP не загружайте вместо файлов сайта.**
5. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, затем **Branch: main** и **Folder: / (root)**, нажмите **Save**.
7. Дождитесь завершения публикации. В разделе Pages появится адрес примерно `https://ваш-логин.github.io/telegram-link-generator/`.
8. Откройте адрес, создайте ссылку и проверьте переход в Telegram на своём телефоне.

Официальная инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site.

Если на компьютере скрыт файл `.nojekyll`, сайт будет работать и без него: в корне нет файлов с именами, которые требуют отключения Jekyll. Не загружайте папки `tests/`, диагностические отчёты, `node_modules/` или ZIP с проверками. В готовом ZIP этих папок нет.

## Что принимает генератор

- Имя пользователя: `example_user`, `@example_user`, `https://t.me/example_user` или `t.me/example_user`.
- Текст: кириллица, эмодзи, переносы строк и обычные URL. До 4096 Unicode-кодовых точек; некоторые эмодзи состоят из нескольких таких точек.
- Пустой текст: обычная ссылка на чат.

Имя проверяется по синтаксису. Приложение не проверяет, существует ли аккаунт, разрешено ли ему писать и ведёт ли введённое имя к человеку, группе, боту или каналу. Указывайте имя нужного человека и проверяйте результат кнопкой «Открыть в Telegram».

Обычные ссылки `t.me/username?text=...` передают текст черновика. Жирное оформление, Markdown и скрытые ссылки внутри слов не передаются как форматирование. В отдельных клиентах Telegram поведение перехода может отличаться; проверьте используемые приложения. Если текст начинается с `@`, клиент Telegram по протоколу может добавить пробел перед ним, чтобы не включить inline-режим.

Длинный текст создаёт длинную ссылку. Telegram может поддерживать сообщение, но редактор сайта или браузер — ограничить длину URL: проверьте вставленную ссылку на целевом сайте. Для кнопки связи удобнее короткое сообщение.

## Данные

Вся обработка происходит в браузере, без аналитики и сторонних запросов. Введённые поля не сохраняются приложением в cookies или localStorage. Браузер может восстановить поля при возврате на страницу. **Текст сообщения входит в URL:** он виден любому, кому передана ссылка, и может попасть в историю браузера после перехода.

## Для разработчика

В исходной папке также есть `PRODUCT.md`, `DESIGN.md` и `tests/`; они не нужны для публикации и исключены из готового ZIP. Проверка логики: `node --test tests/link-core.test.cjs`. Для браузерной проверки нужен Playwright и локальный сервер; команда: `node --test tests/browser.test.cjs` с `TELEGRAM_TEST_URL`, указывающим адрес сайта.

Официальный протокол: https://core.telegram.org/api/links#public-username-links.
